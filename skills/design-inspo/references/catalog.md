# Design Inspiration Catalog

Full reference of curated design galleries, organized by category.

## Web Design (General)

### curated.design
- **Actual URL:** craftwork.design/curated/websites/
- **What:** Curated web design showcase by Craftwork (Bangkok-based design studio)
- **Categories:** Productivity, Tech, Assets, AI, Web3, Design Tools, Dev Tools, Marketing, Portfolio, Agency, E-commerce, Finance, Web Apps, Desktop Apps, Mobile Apps
- **Filters:** Style, Illustrations, Attributes
- **Best for:** Broad web design exploration across industries
- **Pricing:** Free browse, Pro subscription from $16/mo for screen library

## Landing Pages

### landing.love
- **What:** 1,900+ landing page examples with full-page video recordings
- **Best for:** Seeing real landing pages in action (video walkthroughs, not just screenshots)
- **Partners:** Lapa.Ninja, UIStore.Design, Bookmarks.Design
- **Tools featured:** Webflow, Framer
- **Pricing:** Free

## SaaS Websites

### saaspo.com
- **What:** SaaS website design gallery
- **Best for:** B2B/SaaS product page inspiration
- **Note:** Cloudflare-protected, may need browser tool to access
- **Pricing:** Free

## Navigation

### navbar.gallery
- **What:** Dedicated navigation design inspiration (only resource of its kind)
- **Types:** Static/Sticky, Dropdown/Flyout, Mega Menu, Sidebar, Search Bar, Announcement Bar, Full Screen Menu, Breadcrumbs
- **Best for:** Any navigation-related design decision
- **Created by:** Christina Liubynska (supercharged.design)
- **Pricing:** Free

## Call-to-Action

### cta.gallery
- **What:** CTA section design examples
- **Best for:** Conversion-focused section design, button placement, copy patterns
- **Pricing:** Free

## Animation & Motion

### appmotion.design
- **What:** App and web animation/motion design showcase
- **Best for:** Micro-interactions, transitions, loading states, scroll animations
- **Note:** May be intermittently available (Framer-hosted)
- **Pricing:** Free

## Mobile Apps

### mobbin.com
- **What:** 1,150+ iOS & Web apps, 591K+ screens, 313K+ user flows
- **Features:** Video flows with transitions, Figma plugin (copy designs), collections, comments
- **Best for:** Mobile UI patterns, user journeys, specific screen types
- **Pricing:** Free tier available, paid for full access

## Branding

### rebrand.gallery
- **What:** Brand identity redesign showcase
- **Best for:** Before/after rebrand studies, brand evolution, visual identity decisions
- **Pricing:** Free

## Icons

### hugeicons.com
- **What:** Large icon library
- **Best for:** Finding consistent icon sets for UI projects
- **Pricing:** Free + paid tiers

### icoon.co
- **What:** 3D icon collection
- **Best for:** 3D-style UI icons, isometric illustrations
- **Pricing:** Free + paid

## Design Systems & Components

### component.gallery
- **What:** 60+ components across 95 design systems, 2,676 real-world examples
- **Components include:** Carousel, Tree View, Popover, Rating, Accordion, and 55+ more
- **Best for:** Seeing how real design systems implement specific components
- **Pricing:** Free

## Hero Sections

### herocapture.com
- **What:** Hero section design examples
- **Best for:** Above-the-fold design, headline + visual combinations
- **Pricing:** Free
